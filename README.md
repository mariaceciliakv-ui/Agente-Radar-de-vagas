# 🎯 Radar de Vagas — Agente Inteligente de Busca e Fit de Carreira

O **Radar de Vagas** é um agente e painel automatizado desenvolvido para otimizar a busca por oportunidades de emprego, cruzar vagas com o perfil profissional (compatibilidade ATS) e apoiar na preparação para processos seletivos.

## ✨ Principais Funcionalidades

- **Busca Automatizada Multiárea:** Coleta e centraliza vagas filtradas por área de atuação, modelo de trabalho e palavras-chave.
- **Ranqueamento de Compatibilidade (ATS):** Calcula e atualiza automaticamente o nível de aderência entre o currículo e os requisitos de cada vaga.
- **Organização Cronológica:** Exibe as oportunidades da mais recente para a mais antiga, priorizando candidaturas rápidas.
- **Otimização de Currículo e Carreira:** Apoia no diagnóstico de pontos fortes, lacunas técnicas e adaptação do currículo para cada processo seletivo.
- **Dashboard Interativo:** Interface web leve para visualização, filtragem e acompanhamento das vagas encontradas.

## 🛠️ Tecnologias Utilizadas

- **Python** (automação, coleta e tratamento de dados)
- **Inteligência Artificial / Gemini API** (análise de compatibilidade e recomendações)
- **HTML5, CSS3 & JavaScript** (interface e dashboard no GitHub Pages)
- **Excel / Pandas** (estruturação e saída de dados)
